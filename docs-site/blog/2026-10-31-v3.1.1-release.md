v3.1.1 changes no code. It improves what you see on the [npm package page](https://www.npmjs.com/package/@devilsdev/rag-pipeline-utils), which npm builds from the README and `package.json` of each published version.

```bash
npm install @devilsdev/rag-pipeline-utils@^3.1.1
```

<!-- truncate -->

## What changed

- **Code first.** The README now opens with the install command and an example that runs offline, followed by "Why this library". Those points cover what 3.x added: `rag-pipeline eval` and the [GitHub Action](https://github.com/DevilsDev/rag-eval-action), the PostgreSQL/pgvector and Qdrant stores, [contract tests](/docs/Testing#contract-tests-for-your-plugins) for plugins and [context packing](/docs/API-Reference#packcontext).
- **Links that work on npm.** Links to the changelog, the versioning policy, the security policy, the license, the examples and the contributing guide were relative, which works on GitHub but not reliably on npmjs.com. They are absolute now, and a test keeps them that way, along with https-only images and in-page anchors that match a heading.
- **Each version shows its own images.** The banner and the two terminal recordings load from the repository's `main` branch on GitHub. In the published package they now point at the release's tag, so an older version's npm page doesn't change when `main` does, and a new version doesn't wait on the CDN's cache of `main`.
- **Accurate banner.** It said Node.js 18; 3.x needs 22.
- **Homepage and keywords.** The Homepage link in npm's sidebar opens the [documentation](/) instead of the GitHub README, and the keywords include pgvector, qdrant, vector-database, rag-evaluation, llm-evaluation and context-window.

The optional peer dependencies (`openai`, `pg`, `isolated-vm`, `pino-pretty`) are now listed together under Installation, and the comparison with LangChain.js and LlamaIndex.TS reflects the vector stores and providers 3.x supports.

The full list is in the [CHANGELOG](https://github.com/DevilsDev/rag-pipeline-utils/blob/main/CHANGELOG.md).
