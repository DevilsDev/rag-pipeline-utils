## An LLM judge for paraphrases

The answer check compares words, numbers and negation with the sources. That makes it free, fast and the same on every run, but a correct paraphrase shares too few words with its source to pass: "Staff working full time get 20 days of paid leave annually" was reported unsupported against "Full-time employees receive twenty days of paid vacation per year."

Pass `judge`, any LLM with this library's `generate()` contract, and it rules on those sentences:

```js
import { checkAnswer, OpenAIConnector } from "@devilsdev/rag-pipeline-utils";

const check = await checkAnswer({
  answer: "Staff working full time get 20 days of paid leave annually.",
  sources: [
    "Full-time employees receive twenty days of paid vacation per year.",
  ],
  judge: new OpenAIConnector({ apiKey: process.env.OPENAI_API_KEY }),
});

check.grounded; // true when the judge accepts the paraphrase
check.judge.verdicts; // [{ sentence, verdict, sourceId, reason, lexicalReason, decidedBy }]
```

The deterministic check stays in charge:

- **The judge only sees sentences that failed for lack of shared words.** A sentence with a wrong number, or one negated where its source is not, never reaches it and stays unsupported.
- **A "supported" verdict has to name a source, and that source must pass the number and negation checks.** So a judge that says yes to everything still can't accept "thirty days" against a source that says twenty.
- **It fails closed.** Output that isn't the expected JSON, or a source id that doesn't exist, keeps the sentence unsupported.
- **One call per answer** at most, and none when the word check settles everything. `check.judge.calls` and `check.judge.usage` show what it cost.

The [AI SDK middleware](https://devilsdev.github.io/rag-pipeline-utils/docs/Integrations#judge-paraphrases) takes the same option, so `generateText` and `streamText` get the verdicts in `providerMetadata.ragPipeline.judge`. There, a judge that throws, on a rate limit say, doesn't fail the call: the answer comes back and its sentences stay unsupported. See [the LLM judge](https://devilsdev.github.io/rag-pipeline-utils/docs/Evaluation#paraphrases-the-optional-llm-judge) for the details.

## Your documents in Claude, with one command

`@devilsdev/rag-mcp-server` is an MCP server for a folder of documents. It indexes the folder when it starts, offline, and gives Claude, Cursor or any MCP client two tools: `search_documents` returns the best passages with their files, and `check_answer` checks an answer against them sentence by sentence.

```bash
claude mcp add docs -- npx -y @devilsdev/rag-mcp-server /absolute/path/to/docs
```

It reads Markdown, HTML, CSV and text files, needs no API key, database or network, and the MCP SDK stays out of the main package's install. See [the MCP server docs](https://devilsdev.github.io/rag-pipeline-utils/docs/Integrations#mcp-server-for-claude-and-other-mcp-clients), including the Claude Desktop config.
