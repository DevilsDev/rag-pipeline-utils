A patch release: `/edge` on Cloudflare Workers without `nodejs_compat` no longer throws "process.emitWarning is not a function" for cached pipelines and cost estimates.

```bash
npm install @devilsdev/rag-pipeline-utils@^3.9.1
```

<!-- truncate -->

## The edge fix

This affects you if you import `@devilsdev/rag-pipeline-utils/edge` in a
Cloudflare Worker without the `nodejs_compat` flag. Those Workers have no
`process` object, so where the library meant to warn you, it failed
instead: a cached pipeline with a component that has no cache key failed
its run, and `CostCalculator.estimate()` for a model with no price threw.

Now you get the warning in `console.warn`, with its code, and the call
carries on. The same goes for two other warnings: `AnthropicConnector`
sending a request again without a temperature the model rejects, and
`GuardrailsPipeline` when its retrieval guard was skipped. Nothing changes
on Node.js.

## A new look

The [docs site](https://devilsdev.github.io/rag-pipeline-utils/) and the
README have a new look, with new fonts and colours, and the
[Comparison page](https://devilsdev.github.io/rag-pipeline-utils/docs/Comparison)
now lets you filter its table and compare one framework at a time.

The scoped packages, `@devilsdev/rag-mcp-server` and `create-rag-pipeline`
are released at 3.9.1 too, unchanged apart from the version.

The full list is in the [CHANGELOG](https://github.com/DevilsDev/rag-pipeline-utils/blob/v3.9.1/CHANGELOG.md).
