Documentation and package metadata only; no code changes. The security fixes are in 3.8.2: if you're on 3.8.1 or earlier, upgrade for them (see the [v3.8.2 release](https://github.com/DevilsDev/rag-pipeline-utils/releases/tag/v3.8.2)).

```bash
npm install @devilsdev/rag-pipeline-utils@^3.8.3
```

## What changed

The npm page is the first thing most people see, so this release makes it
say what the library does in one line:

> RAG for Node.js that tells you when your LLM is making things up.

That line is now the README headline, the npm description and the text of
the banner, which no longer repeats the package name under the heading.

The package also lists the keywords people search for when they look for
this kind of check: `hallucination`, `hallucination-detection`,
`grounding`, `fact-checking`, `mcp`, `vercel-ai-sdk`, `mastra` and
`langchain`.

And the "Take only what you need" table now gives the installed size of
every package, from under 1 MB for `create-rag-pipeline` to about 34 MB for
the main package, so you can pick the smallest one that does the job.

The scoped packages, `@devilsdev/rag-mcp-server` and `create-rag-pipeline`
are released at 3.8.3 too, unchanged apart from the version.

The full list is in the [CHANGELOG](https://github.com/DevilsDev/rag-pipeline-utils/blob/v3.8.3/CHANGELOG.md).
