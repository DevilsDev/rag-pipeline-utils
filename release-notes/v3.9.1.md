A patch release: `/edge` on Cloudflare Workers without `nodejs_compat` no longer throws "process.emitWarning is not a function" for cached pipelines and cost estimates.

```bash
npm install @devilsdev/rag-pipeline-utils@^3.9.1
```

No new features or options; upgrade if you use `@devilsdev/rag-pipeline-utils/edge`.

## Fixed

- **Warnings on `/edge` no longer throw.** On Workers without `nodejs_compat` there is no `process`, so `process.emitWarning` was missing: a cached pipeline whose embedder, retriever or LLM has no cache key failed its run, and `CostCalculator.estimate()` for a model with no price threw. These warnings now go to `console.warn` as "[CODE] Type: message", as do `AnthropicConnector`'s when it sends a request again without a temperature the model rejects, and `GuardrailsPipeline`'s when its retrieval guard was skipped. Node's own `process` is used as it is, and Vercel Edge's `process` is wrapped, not changed. The workerd edge test checks all four.

## Changed

- **New README images and badges:** a new banner, a "What checkAnswer catches" card and a feature strip, in the docs site's fonts and colours, and badges to match.

The scoped packages, `@devilsdev/rag-mcp-server` and `create-rag-pipeline` are released at 3.9.1 too, unchanged apart from the version.
