Documentation and package metadata only; no code changes. The security fixes are in 3.8.2: if you're on 3.8.1 or earlier, upgrade for them ([v3.8.2 release](https://github.com/DevilsDev/rag-pipeline-utils/releases/tag/v3.8.2)).

```bash
npm install @devilsdev/rag-pipeline-utils@^3.8.3
```

## Changed

- **One tagline everywhere:** "RAG for Node.js that tells you when your LLM is making things up." in the README, the npm description and the banner.
- **Easier to find on npm:** new keywords `hallucination`, `hallucination-detection`, `grounding`, `fact-checking`, `mcp`, `vercel-ai-sdk`, `mastra` and `langchain`.
- **A tidier npm page:** the banner no longer repeats the package name, and the package table gives the installed size of every package.

The scoped packages, `@devilsdev/rag-mcp-server` and `create-rag-pipeline` are released at 3.8.3 too, unchanged apart from the version. Full details: [CHANGELOG](https://github.com/DevilsDev/rag-pipeline-utils/blob/main/CHANGELOG.md) · [Blog post](https://devilsdev.github.io/rag-pipeline-utils/blog/v3-8-3-release)
