A minor release with **no breaking changes**. It adds a Weaviate retriever and support for Pinecone indexes that embed text themselves. The answer check now reads units, fractions and times, and the CLI explains a missing or wrong API key in one line.

```bash
npm install @devilsdev/rag-pipeline-utils@^3.7.0
```

## Highlights

- **`WeaviateRetriever`.** It uses Weaviate's REST and GraphQL APIs with the built-in `fetch`, so there's no client package to install, and it runs on the edge build too.

  - On the first `store()` it creates a collection for vectors you provide.
  - It passes the same retriever contract as pgvector, Qdrant and Pinecone, against Weaviate 1.40.4 in CI.

  [Weaviate](https://devilsdev.github.io/rag-pipeline-utils/docs/Concepts-Connectors#weaviate)

- **Pinecone indexes that embed text themselves.** This includes the console's quick-start indexes, which 3.6.0 refused.

  - Documents are stored as text, and queries search by text with Pinecone's own model, so neither a pipeline nor the CLI's `ingest` needs an embedder there.
  - It was tested live on real indexes of all three kinds Pinecone offers.

  [Pinecone](https://devilsdev.github.io/rag-pipeline-utils/docs/Concepts-Connectors#pinecone) · [CLI without an embedder](https://devilsdev.github.io/rag-pipeline-utils/docs/CLI#no-embedder-a-retriever-that-embeds-text)

## Fixed

- **Units, fractions and times in the answer check.**

  - A number with a unit is checked as a quantity, converted exactly within its kind: "2 kg" matches "2,000 grams", and "2 pounds" no longer passes against "2 kilograms".
  - "Three quarters of" reads as 75%.
  - "5 pm" matches 17:00 when the source states clock times.
  - Two false alarms that 3.6's clause rule added are fixed.

  On every SciFact citation claim the check flagged, reviewed by hand, false alarms fell from 43 to 35 across five Claude models, with the 3 real problems still caught. [3.6.0 and 3.7 compared](https://devilsdev.github.io/rag-pipeline-utils/docs/Benchmarks#360-and-37-compared)

- **DAG timeouts no longer keep the process alive.** A `DAGEngine` run with a `timeout`, including `AgenticPipeline`'s 60-second default, held the process open for the whole timeout after it finished.
- **The logger no longer adds a process `exit` listener.** It writes synchronously. Repeated module loads, as in a test runner, no longer print MaxListeners warnings.
- **package.json is in the form npm publishes,** for all seven packages.

## Changed

- **The CLI names the key in one line.** With a missing or refused API key, it says which key to set and what the API said, with no stack trace (unless `--verbose`). It never prints the key.
- **Grounding verdicts can change** for `checkAnswer`, `verifyCitations`, `CitationTracker`, `PostGenerationGuard` and the judge's failure classification. Re-save the report you pass to `rag-pipeline eval --baseline`.

The scoped packages, `@devilsdev/rag-mcp-server` and `create-rag-pipeline` are released at 3.7.0 too. Full details: [CHANGELOG](https://github.com/DevilsDev/rag-pipeline-utils/blob/main/CHANGELOG.md) · [Blog post](https://devilsdev.github.io/rag-pipeline-utils/blog/v3-7-release)
